# A Foundational Curriculum for the Full-Stack LLM Engineer

This comprehensive curriculum covers the essential skills needed to become a full-stack LLM engineer, from statistical foundations to datacenter engineering.

## Course Structure

### Pillar I: Statistical and Algorithmic Foundations of Language Models
* **[Course 1: Probabilistic Methods in NLP](/modules/course1/ngram-model/)** - N-gram models, Markov chains, and language model evaluation
* **[Course 2: Modern LLM Architectures](/modules/course2/neural-networks/)** - From n-grams to Transformers and Retrieval-Augmented Generation

### Pillar II: High-Performance GPU Kernel Programming
* **[Course 3: CUDA Architecture and Programming](/modules/course3/cuda-model/)** - CUDA execution model, memory optimization, and GEMM optimization lab
* **[Course 4: Advanced Kernel Fusion](/modules/course4/memory-wall/)** - Kernel fusion techniques, FlashAttention, and fused operations

### Pillar III: Architectures for Scaling and Distribution
* **[Course 5: Collective Communications](/modules/course5/collectives/)** - Collective operations, Ring-AllReduce, and fault tolerance
* **[Course 6: Model Parallelism](/modules/course6/data-parallelism/)** - Data parallelism, model splitting, and hybrid strategies

### Pillar IV: The Physical Layer: Datacenter Engineering for AI
* **[Course 7: High-Performance Interconnects](/modules/course7/intra-node/)** - Network topologies and high-speed interconnects
* **[Course 8: Datacenter Physics](/modules/course8/power-density/)** - Power management, cooling solutions, and storage systems

### Final Project
* **[Capstone Project](/modules/capstone/architectural-design/)** - Design a complete architecture for a frontier LLM
